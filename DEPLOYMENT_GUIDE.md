## Installation Steps

### Step 1: Download the Token Guard Wrapper

First, download the latest version of the Token Guard wrapper from the official repository or website. Ensure you have a stable internet connection.

```powershell
# Navigate to the directory where you want to save the installer
cd C:\Temp

# Download the Token Guard wrapper installer
Invoke-WebRequest -Uri "https://example.com/token-guard-wrapper-installer.zip" -OutFile "token-guard-wrapper.zip"
```

### Step 2: Extract the Installer

Extract the contents of the downloaded zip file.

```powershell
# Unzip the downloaded file
Expand-Archive token-guard-wrapper.zip -DestinationPath C:\TokenGuardWrapper
```

## PowerShell Alias Setup

### Step 1: Create a New Directory for Aliases

Create a directory to store your aliases and scripts for easy access.

```powershell
# Create a new directory for aliases
New-Item -ItemType Directory -Path "C:\Aliases"
```

### Step 2: Add the Token Guard Wrapper Alias

Add an alias to quickly call the Token Guard wrapper executable from anywhere in PowerShell.

```powershell
# Set the path to the Token Guard wrapper executable
$tokenGuardWrapperPath = "C:\TokenGuardWrapper\bin\Release\netcoreapp3.1\TokenGuardWrapper.exe"

# Add a PowerShell alias for easy access
Set-Alias -Name tgw -Value $tokenGuardWrapperPath
```

### Step 3: Verify the Alias

Run the following command to verify that the alias is set correctly.

```powershell
# Check if the alias is available
Get-Command tgw
```

## Bash Alias Setup (for Git Bash users)

If you are using Git Bash on Windows, follow these steps to create a bash alias for the Token Guard wrapper.

### Step 1: Create a New Directory for Aliases

Create a directory to store your aliases and scripts for easy access.

```bash
# Create a new directory for aliases
mkdir -p ~/.bash_aliases.d/TokenGuardWrapper
```

### Step 2: Add the Token Guard Wrapper Alias

Add an alias to quickly call the Token Guard wrapper executable from anywhere in Git Bash.

```bash
# Open or create your .bashrc file
nano ~/.bashrc

# Add the following line at the end of the file
alias tgw='C:/TokenGuardWrapper/bin/Release/netcoreapp3.1/TokenGuardWrapper.exe'
```

### Step 3: Reload the Bash Configuration

Reload the bash configuration to apply the new alias.

```bash
source ~/.bashrc
```

### Step 4: Verify the Alias

Run the following command to verify that the alias is set correctly.

```bash
# Check if the alias is available
alias tgw
```

## Uninstall Instructions

### Step 1: Remove Aliases

Remove any aliases you created for the Token Guard wrapper.

```powershell
# Remove the PowerShell alias
Remove-Item -Path "C:\Aliases\tgw"

# For Git Bash users, remove the alias from ~/.bashrc
sed -i '/tgw/d' ~/.bashrc
source ~/.bashrc
```

### Step 2: Uninstall the Token Guard Wrapper

Uninstall the Token Guard wrapper by removing its directory.

```powershell
# Remove the Token Guard wrapper installation directory
Remove-Item -Recurse -Force "C:\TokenGuardWrapper"
```

### Step 3: Clean Up

Clean up any remaining files or directories related to the Token Guard wrapper.
